# Scraping Manager

## Описание
**Scraping Manager** — это приложение для парсинга вакансий с сайта hh.ru, их сохранения в базу данных и отображения через веб-интерфейс. Приложение построено с использованием FastAPI, SQLAlchemy и Jinja2.

## Функциональность
- Парсинг вакансий с hh.ru для указанного города.
- Сохранение данных о вакансиях в базу данных SQLite.
- Веб-интерфейс для отображения вакансий в виде таблицы.
- Возможность запуска парсинга через веб-форму.
